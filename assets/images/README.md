# Character & App Assets

Drop your hand-drawn character illustrations here:
1. `character_enhancer.png`: The "Appetite Enhancer" imp (Warm color tones, girly vibe).
2. `character_suppressant.png`: The "Appetite Suppressant" imp (Cool color tones, boyish/shota vibe).

### Notes:
- Recommended format: Transparent PNG (approx. 512x512 or 1024x1024).
- The Flutter app automatically checks for these files and gracefully falls back to the Nordic minimalist vector placeholder if the files are not yet present.
